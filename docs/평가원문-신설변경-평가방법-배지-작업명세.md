## 화면 규칙

- 평가방법은 원문 표현: 면담, 현장, 시연, 기록, 전산, 유선.
- 원문에 `현장확인`은 없다. 파서 식별자는 남겨 두되 원문에 없으면 표시하지 않는다.
- 상위 화면 평가방법: 해당 지표 세부 기준 방법의 중복 없는 합집합.
- 상세 화면: 그 세부 기준의 방법만.
- 배지는 정지한다. 반복 애니메이션, 시작 지연, 호버·포커스 이동·확대는 없다.
- 색·글자·테두리·줄바꿈·링크의 키보드 포커스는 유지한다.

## 2026-10-15 재추출 확인 보존·원격 비교

파서 `sec()`는 빈 텍스트를 항상 `needsReview: true`(추출 실패·미확인)로 둔다. ‘원문에 섹션 없음’ 확인은 `src/data/confirmed-absences.json`에 둔다. 각 기록은 `pdfFile` + `pdfSha12` + 지표 + 섹션 + `filePages` + 근거 문장이다.

- sha가 같을 것
- 지표 filePages와 기록 filePages가 겹칠 것

- 해당 기록만 해제. 빈 예시·주의 등 다른 공란은 그대로 검토

다른 sha(원문 변경)이면 적용하지 않아 다시 검토 상태가 된다. `scripts/rebuild-preview-from-pdf.ts`는 파싱 후 적용한다. `--out=`으로 다른 경로에 쓸 수 있다.
